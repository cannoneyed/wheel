## Source-of-truth rules

1. Source declarations and tests override prose.
2. `docs/*.mdx` explains the human workflow. `docs/robots/*.md` carries operational detail.
3. `docs/robots/api/*.md` is generated by `bun run docs:robots`.
4. Future plans do not belong in this tree. Current limits are explicit.
5. Server-only imports stay outside browser modules.
